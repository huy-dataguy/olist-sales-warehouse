# Dossier admission

Current state: no admitted dossier. Source research and semantic compilation are bounded checks, not a working integration slice.

specs/executable-dossier/dossier.template.json is the unchanged template baseline. Fill dossier.json only after actual implementation/runbook commands exist. Never point admission at planned make targets.

Before eventual admission: stable requirement/task mapping, existing artifacts/contracts, verified runbook paths, expected exit codes, real storage/runtime evidence, task-graph validation and applicable migration authority must be present.

The native DSH validate_task_graph tool is not exposed in this session. Local design validation checks references and acyclicity; it does not claim DSH admission. Use the native integration when performing a real handoff.
